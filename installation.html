Method 1: Upload ZIP File (Recommended)

1

Access Shopify Admin

Log in to your Shopify admin panel at: your-store.myshopify.com/admin

2

Navigate to Themes

From the left sidebar, click: Online Store → Themes

3

Add Theme

Scroll down to the "Theme Library" section and click "Add theme"

4

Upload ZIP File

Click "Upload ZIP file" from the dropdown menu

Note: Make sure you have the YUMI theme ZIP file ready. Do not unzip the file before uploading.

5

Select File

Click "Choose File" and select yumi-v1.0.0.zip from your computer

6

Wait for Upload

The theme will upload and install automatically. This may take 1-3 minutes.

7

Preview Theme

Once uploaded, YUMI will appear in your Theme Library. Click "Customize" to preview and edit

Method 2: Shopify CLI (Advanced)

⚠️ For Developers: This method requires command-line knowledge and is recommended for developers working on theme customization.

Prerequisites

  • ✅ Node.js (LTS version) installed
  • ✅ Shopify CLI installed
  • ✅ Git installed (optional)
  • ✅ Shopify Partner account or staff access

Installation Steps

1. Install Shopify CLI

# Using npm
npm install -g @shopify/cli @shopify/theme

# Using Homebrew (Mac)
brew tap shopify/shopify
brew install shopify-cli

2. Navigate to Theme Directory

cd /path/to/yumi-theme

3. Connect to Your Store

shopify theme push --store your-store.myshopify.com

4. Or Use Development Mode

shopify theme dev --store your-store.myshopify.com

This creates a development theme and provides a preview URL

Post-Installation Checklist

Essential Setup Steps

  • ☐ Upload Logo: Theme Settings → Logo → Upload your logo image
  • ☐ Set Favicon: Theme Settings → Logo → Upload favicon (32x32px)
  • ☐ Configure Colors: Theme Settings → Colors → Customize color schemes
  • ☐ Select Fonts: Theme Settings → Typography → Choose heading and body fonts
  • ☐ Setup Navigation: Online Store → Navigation → Configure menus
  • ☐ Configure Cart: Theme Settings → Cart → Choose cart type (drawer/page/notification)
  • ☐ Add Social Links: Theme Settings → Social Media → Add your social profiles
  • ☐ Enable Swatches: Theme Settings → Color Swatches → Configure product swatches

Homepage Configuration

  • ☐ Add Header: Customize → Add header section
  • ☐ Add Hero Banner: Add Image Banner or Slideshow section
  • ☐ Add Collections: Add Featured Collection or Collection List section
  • ☐ Add Content Sections: Add Image with Text, Multicolumn, etc.
  • ☐ Add Footer: Customize footer with your information

Testing & Quality Assurance

  • ☐ Test on desktop browsers (Chrome, Firefox, Safari, Edge)
  • ☐ Test on mobile devices (iOS and Android)
  • ☐ Test checkout process
  • ☐ Test product pages with different variants
  • ☐ Test cart functionality
  • ☐ Test search functionality
  • ☐ Test all navigation menus

Common Installation Issues

❌ Upload Failed / File Too Large

Problem: ZIP file exceeds Shopify's upload limit

Solution:

  • Ensure you're uploading the correct theme ZIP file
  • The ZIP should be under 50MB
  • Use Shopify CLI method if upload fails repeatedly

❌ Theme Not Appearing After Upload

Problem: Theme doesn't show in Theme Library

Solution:

  • Refresh your browser
  • Check if upload completed successfully (no error messages)
  • Try uploading again
  • Clear browser cache

❌ Theme Editor Not Loading

Problem: Customize button doesn't work or editor is blank

Solution:

  • Clear browser cache and cookies
  • Try a different browser
  • Disable browser extensions temporarily
  • Check your internet connection

❌ Sections Missing or Not Working

Problem: Some sections don't appear in the editor

Solution:

  • Verify complete theme upload (check file size)
  • Re-upload the theme
  • Contact support with specific section names

❌ Errors After Publishing

Problem: Theme shows errors on live site

Solution:

  • Always preview before publishing
  • Check if all required settings are configured
  • Revert to previous theme if needed
  • Contact support with error details and screenshots

Migration from Another Theme

⚠️ Important: Always backup your current theme before switching. Shopify keeps theme backups, but it's good practice to download a copy.

Data That Transfers Automatically

  • ✅ Products and collections
  • ✅ Customer data
  • ✅ Orders
  • ✅ Navigation menus
  • ✅ Pages and blog posts

Data That Needs Reconfiguration

  • ⚙️ Theme settings (colors, fonts, etc.)
  • ⚙️ Homepage layout and sections
  • ⚙️ Custom CSS/JavaScript
  • ⚙️ Third-party app integrations
  • ⚙️ Custom page templates

Migration Steps

  1. Install YUMI as outlined above (don't publish yet)
  2. Customize YUMI to match your brand
  3. Test thoroughly using preview mode
  4. Schedule migration during low-traffic hours
  5. Publish YUMI theme
  6. Test all functionality immediately
  7. Monitor for 24-48 hours
