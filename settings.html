Logo & Favicon

Customize your store's branding with your logo and favicon.

Logo Image

Location: Theme Settings → Logo → Logo Image

Type: Image Upload

Specifications:

  • Recommended Size: 400px × 200px (or proportional)
  • Format: PNG (with transparency) or SVG
  • Max File Size: 500KB
  • Color Mode: RGB
💡 Tip: Use a PNG with transparent background for best results. SVG files provide perfect scaling at any size.

Logo Width

Location: Theme Settings → Logo → Logo Width

Type: Range Slider (50px - 300px)

Default: 100px

Controls the maximum width of your logo on desktop. Mobile size adjusts automatically.

Favicon

Location: Theme Settings → Logo → Favicon

Type: Image Upload

Specifications:

  • Required Size: 32px × 32px or 64px × 64px
  • Format: PNG or ICO
  • Design: Simple, recognizable at small sizes

Color Swatches

Display product color variants as visual swatches instead of dropdowns.

Swatch Option Name

Type: Text

Default: "Color"

The exact name of your variant option (case-sensitive).

For multilingual stores: Enter multiple options separated by commas.
Example: Color,Colour,Farbe,Couleur

Swatch Type

Type: Dropdown

Options:

  • Color: Uses color codes or images
  • Variant Image: Uses the variant's product image

Default: Color

Colors Configuration

Type: Textarea

Define color swatches using this format:

Black:#000000
White:#f5f5f5
Blue:#005eff
Red:#c9002c

Advanced Options:

Two-color swatches:

Red&Blue:#c9002c#005eff

Three-color swatches:

Tri-color:#ff0000#00ff00#0000ff

Image swatches:

Green kaki:green-kaki.png

Upload images to Files, use lowercase names with hyphens

💡 Default Colors Included: Black, White, Blue, Red, Pink, Brown, Olive, Purple, Grey, Beige, Yellow, Orange, Green

Show Color Swatches on Collection Page

Type: Checkbox

Default: Enabled

Display color swatches on product cards in collection pages.

Swatch Style

Type: Dropdown

Options:

  • Round
  • Square
  • Square with round corners
  • Portrait

Swatch Size (Product Page)

Type: Range Slider

Range: 20px - 60px

Default: 40px

Collection Page Swatch Size

Type: Range Slider

Range: 15px - 40px

Default: 25px

Color Schemes

YUMI uses a color scheme system for consistent design across your store.

Color Scheme Groups

Each color scheme includes:

  • Background: Main background color
  • Background Gradient: Optional gradient overlay
  • Text: Primary text color
  • Button Background: Primary button color
  • Button Label: Button text color
  • Secondary Button Label: Secondary button text
  • Shadow: Shadow color for depth

Cart Bubble Colors

Location: Theme Settings → Colors → Cart Bubble

  • Cart Bubble Background: Default #000000
  • Cart Bubble Text: Default #FFFFFF
💡 Best Practice: Create 3-5 color schemes to maintain visual consistency while providing variety for different sections.

Typography

Control fonts and text sizes across your store.

Headings

Heading Font

Type: Font Picker

Choose from Shopify's font library or upload custom fonts.

Popular Choices: Montserrat, Raleway, Playfair Display, Lora

Heading Scale

Type: Range Slider

Range: 100% - 200%

Default: 120%

Adjusts the size of all headings proportionally.

Body Text

Body Font

Type: Font Picker

Choose your main paragraph font.

Popular Choices: Inter, Open Sans, Roboto, Lato

Body Scale

Type: Range Slider

Range: 100% - 150%

Default: 110%

Adjusts body text size globally.

💡 Accessibility: Keep body text at least 16px (100%) for optimal readability.

Buttons & Form Elements

Button Styling

Border Thickness

Range: 0px - 12px | Default: 1px

Border Opacity

Range: 0% - 100% | Default: 100%

Corner Radius

Range: 0px - 40px | Default: 0px

0px = sharp corners, 40px = fully rounded

Shadow Settings

  • Shadow Opacity: 0% - 100% (Default: 0%)
  • Horizontal Offset: -12px to 12px (Default: 0px)
  • Vertical Offset: -12px to 12px (Default: 0px)
  • Shadow Blur: 0px - 20px (Default: 0px)

Variant Pills Styling

Style for variant option buttons (size, material, etc.)

  • Border Thickness: 0-12px (Default: 1px)
  • Border Opacity: 0-100% (Default: 55%)
  • Corner Radius: 0-40px (Default: 40px)
  • Shadow controls (same as buttons)

Input Fields Styling

  • Border Thickness: 0-12px (Default: 1px)
  • Border Opacity: 0-100% (Default: 55%)
  • Corner Radius: 0-40px (Default: 12px)
  • Shadow controls (same as buttons)
