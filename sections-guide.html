About Sections

YUMI includes 70+ customizable sections that you can drag and drop to create your perfect store layout. All sections are Shopify 2.0 compatible and can be added to any page.

How to Add Sections:

  1. Go to Theme Editor (Customize)
  2. Click "Add section" button
  3. Browse categories or search for specific section
  4. Click section to add it to your page
  5. Configure section settings in the right panel

Hero & Banner Sections

📸 Image Banner

Large hero image with text overlay and call-to-action button.

📸 Screenshot: Image Banner section example

Show full-width hero with overlay text

Key Settings:

  • Image: Desktop image (1920x800px recommended)
  • Mobile Image: Optional mobile-specific image (800x1000px)
  • Image Height: Small / Medium / Large / Adapt to image
  • Heading: Main headline text
  • Text: Supporting description
  • Button Label: CTA button text
  • Button Link: Button destination URL
  • Text Alignment: Left / Center / Right
  • Color Scheme: Choose from available schemes
  • Overlay Opacity: 0-100% dark overlay
💡 Best Practice: Use high-quality images with clear focal points. Keep text readable with sufficient contrast.

🎬 Slideshow

Rotating carousel of hero images with individual settings for each slide.

📸 Screenshot: Slideshow with multiple slides

Key Settings:

  • Slide Height: Adapt to first image / Small / Medium / Large
  • Auto-rotate: Enable/disable automatic sliding
  • Change slides every: 3-10 seconds
  • Per Slide Settings:
    • Image upload
    • Heading and text
    • Button configuration
    • Text position

📢 Announcement Bar

Top bar for important announcements, sales, or free shipping messages.

  • Text: Announcement message

  • Color Scheme: Background and text colors
  • Show on: All pages / Homepage only

🎁 Featured Collection

Display products from a specific collection in a grid layout.

📸 Screenshot: Featured Collection grid

Key Settings:

  • Collection: Select collection
  • Heading: Section title
  • Description: Optional collection description
  • Products to Show: 4 / 8 / 12 / 16 products
  • Columns (Desktop): 2 / 3 / 4 / 5 columns
  • Columns (Mobile): 1 / 2 columns

  • Image Ratio: Portrait / Square / Landscape / Adapt
  • Show Secondary Image: Hover effect image
  • Enable Quick Add: Add to cart from collection
