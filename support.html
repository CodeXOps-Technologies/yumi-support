Frequently Asked Questions

📦 Installation & Setup

Q: How do I install the theme?

A: Go to your Shopify admin → Online Store → Themes → Add theme → Upload ZIP file. Select the YUMI theme ZIP and upload. See our Installation Guide for detailed steps.

Q: Can I preview the theme before publishing?

A: Yes! After uploading, click "Customize" to preview and edit the theme without affecting your live store. Only click "Publish" when you're ready to go live.

Q: Will installing YUMI delete my products/content?

A: No! Your products, collections, customers, and orders are stored separately from your theme. Only the visual design changes.

Q: Can I switch back to my old theme?

A: Yes. Shopify keeps your previous themes. Go to Themes → Theme Library and click "Publish" on your old theme to revert.

🎨 Customization

Q: How do I change colors?

A: Go to Theme Settings → Colors. YUMI uses color schemes that you can customize. Each scheme controls multiple elements for consistent design.

Q: Can I use custom fonts?

A: Yes! Go to Theme Settings → Typography. You can choose from Shopify's font library or upload custom fonts (in supported formats).

Q: How do I add my logo?

A: Theme Settings → Logo → Upload your logo image. PNG with transparent background recommended. Adjust logo width using the slider.

Q: Can I add sections to any page?

A: Yes! YUMI is Shopify 2.0 compatible, so you can add sections to homepage, product pages, collection pages, and custom pages.

🛒 Products & Collections

Q: How do I setup color swatches?

A: Go to Theme Settings → Color Swatches. Configure the color option name (e.g., "Color") and add color codes in the format: Red:#ff0000. See Color Swatches documentation.

Q: Why aren't my color swatches showing?

A: Check: 1) The variant option name matches exactly (case-sensitive), 2) Colors are defined in settings, 3) "Show swatches" is enabled, 4) Your product has a color variant.

Q: Can I change the product grid layout?

A: Yes! Each Featured Collection section has settings for columns (desktop and mobile) and image ratio. Adjust in the section settings.

Q: How do I enable quick add to cart?

A: In Featured Collection or Collection Grid sections, enable "Enable quick add" in section settings.

🎯 Navigation & Menus

Q: How do I create a mega menu?

A: 1) Create your navigation menu in Shopify (Navigation), 2) In Header section settings, select "Mega Menu" type, 3) Configure mega menu settings in Theme Settings → Extended Mega Menu.

Q: How many menu items can I have?

A: Shopify allows up to 50 menu items per menu. For mega menus, we recommend 5-8 top-level items for best UX.

Q: Can I add images to menu items?

A: Yes, with Extended Mega Menu or Image Mega Menu enabled. Configure in Theme Settings → Extended Mega Menu.

🛍️ Cart & Checkout

Q: What's the difference between cart drawer and cart page?

A: Cart drawer slides in from the side without leaving the page (recommended). Cart page is a dedicated page. Cart notification shows a small popup.

Q: How do I setup the free shipping bar?

A: Theme Settings → Free Shipping Bar. Enable it and set your free shipping threshold amount.

Q: Can I add recommended products in the cart?

A: Yes! Theme Settings → Cart → Cart Drawer Collection. Select a collection to show as recommendations.

⚡ Performance

Q: How can I improve my store's speed?

A: 1) Optimize images (use WebP, compress files), 2) Limit number of sections per page, 3) Reduce app count, 4) Use Shopify's image CDN, 5) Enable lazy loading (default in YUMI).

Q: Why is my site slow?

A: Common causes: Too many apps, large unoptimized images, too many third-party scripts. Use Google PageSpeed Insights to identify issues.

📱 Mobile & Responsive

Q: Is YUMI mobile-friendly?

A: Yes! YUMI is built mobile-first and fully responsive on all devices.

Q: Can I hide sections on mobile?

A: Most sections have a "Show on mobile" toggle in their settings.

Q: How do I test mobile view?

A: In theme editor, use the device preview buttons at the top, or test on actual mobile devices for best results.

🌐 Multi-language & Markets

Q: Does YUMI support multiple languages?

A: Yes! YUMI is translation-ready. Use Shopify's Markets or third-party translation apps.

Q: How do I add language selectors?

A: Enable Markets in Shopify, then add the language selector in Header section settings.

🔧 Technical Issues

Q: My changes aren't saving!

A: 1) Clear browser cache, 2) Try a different browser, 3) Ensure stable internet connection, 4) Check if you clicked "Save" button, 5) Disable browser extensions temporarily.

Q: Section isn't displaying correctly!

A: 1) Check section visibility settings, 2) Verify color scheme contrast, 3) Ensure required fields are filled, 4) Clear cache and refresh, 5) Contact support with screenshots.

Q: Theme editor is blank/not loading!

A: 1) Clear browser cache and cookies, 2) Try incognito/private mode, 3) Try different browser, 4) Disable browser extensions, 5) Check internet connection.

Q: How do I report a bug?

A: Email support@codexops.com with: 1) Detailed description, 2) Steps to reproduce, 3) Screenshots, 4) Browser and device info, 5) Store URL (if possible).

  1. Go to Theme Settings → Colors
  2. Click on a color scheme to edit
  3. Set Background color
  4. Set Text color (ensure good contrast)
  5. Set Button colors
  6. Preview changes on different sections
  7. Create 3-5 schemes for variety
  8. Save settings

📸 Optimizing Images

Recommended Image Sizes:

  • Product Images: 2048x2048px, square ratio
  • Collection Images: 1200x1200px (square) or 1200x1600px (portrait)
  • Hero Banners: 1920x800px (desktop), 800x1000px (mobile)
  • Logo: 400x200px max, PNG with transparency
  • Favicon: 32x32px or 64x64px

Optimization Tips:

  • Use WebP format when possible
  • Compress images before uploading (TinyPNG, ImageOptim)
  • Don't upload images larger than needed
  • Use Shopify's image CDN (automatic)
